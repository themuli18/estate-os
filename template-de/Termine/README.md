# Termine

Eine Datei je tatsächlich vereinbartem Termin – keine Vorbereitung auf Vorrat.

Name: `JJJJ-MM-TT_Stelle_Thema.md`. Aufbau:

1. **Ziel** – was nach dem Termin geregelt sein soll.
2. **Mitbringen** – Unterlagen (mit Pfad in `Dokumente/`), Ausweis, Nummern.
3. **Fragen** – nummeriert, damit das Ergebnis darauf verweisen kann.
4. **Ergebnis** – nach dem Termin: Antworten je Frage, Absprachen, neue Fristen (→ `TODO.md` und `CLAUDE.md` Abschnitt 7).

Gespräche nur mit Einverständnis aufzeichnen (§ 201 StGB); transkribieren mit `_tools/transkribiere.sh`.
