# Afspraken

Eén bestand per concrete, gemaakte afspraak – geen voorbereiding op voorraad.

Naam: `JJJJ-MM-DD_Instantie_Onderwerp.md`. Opbouw:

1. **Doel** – wat moet er na afloop geregeld zijn.
2. **Meenemen** – documenten (met pad in `Documenten/`), legitimatie, nummers.
3. **Vragen** – genummerd, zodat het verslag ernaar kan verwijzen.
4. **Verslag** – na afloop invullen: antwoorden per vraag, afspraken, nieuwe termijnen (→ `TODO.md` en `CLAUDE.md` sectie 7).

Opnames van gesprekken alleen met toestemming; transcriberen met `_tools/transcribeer.sh`.
